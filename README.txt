AP TRADE HUB — EASY CATALOGUE

How to add a new product:
1. Open products.json
2. Copy any existing product object
3. Change:
   - id      = unique short ID
   - name    = product name
   - cat     = category
   - cost    = reference/cost price
   - price   = selling/quoted price
   - img     = product image URL
   - badge   = small label
   - desc    = short description
4. Save products.json.
5. Upload products.json alongside index.html.

IMPORTANT:
- Keep index.html and products.json in the same folder.
- You no longer need to edit the product list inside index.html.
- Future catalogue updates only require products.json.
